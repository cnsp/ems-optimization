# distance_comparison/ — ✅ CURRENT

Manhattan vs Haversine distance metric comparison.

## Key Finding
P2 allocation is robust to the choice of distance metric. Manhattan distance provides an upper-bound approximation to Haversine.

## Files
- `allocation_comparison.csv` — Haversine vs Manhattan allocations
- `comparison_table.csv` — Side-by-side performance metrics
- `distance_comparison_bar.png` — Bar chart comparison
- `distance_comparison_boxplot.png` — Distribution comparison
- `distance_matrices_heatmap.png` — Heatmap of both distance matrices
- `distance_scatter.png` — Scatter plot of Haversine vs Manhattan
- `experiment_log.txt` — Run metadata
