# cbd_focused_comparison/ — ✅ CURRENT

Results from CBD-focused optimization experiment.

## Key Finding
CBD demand weighting (3x) does NOT improve CBD response time but significantly degrades non-CBD response time. Standard P2 is preferred.

## Files
- `allocations.csv` — CBD-focused vs standard allocations
- `comparison_table.csv` — Side-by-side metrics
- `cbd_focused_comparison.png` — Visual comparison
- `allocation_comparison.png` — Allocation map comparison
- `equity_tradeoff.png` — Equity analysis
- `experiment_log.txt` — Run metadata
