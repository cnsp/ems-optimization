## 3. PROVENANCE ISSUES

### 🔴 CRITICAL Issues

#### Issue 1: `capacity_sensitivity_heatmap.png` is BROKEN and NOT REPRODUCIBLE
- **Referenced in:** `docs/core/technical_report.md:670` (Figure 6)
- **Location:** `results/archive/figures/` (archive tier)
- **Problem:** The uploaded screenshot confirms the figure displays "Data format issue" for K=20 and K=40 panels — it shows blank heatmap panels with error text.
- **Root cause:** Both `generate_capacity_sensitivity_heatmap.py` and `regenerate_all_figures.py` read from `results/capacity_comparison/` which **does not exist**. Data was relocated to `results/analysis/capacity_comparison/` during directory restructuring.
- **The fix documented in `fleet_sensitivity_dual_investigation.md`** (POLICY_LABELS mapping) was applied to the script but the figure was never regenerated after the directory move.
- **Impact:** Figure 6 in the technical report is broken/misleading.

#### Issue 2: `regenerate_all_figures.py` has STALE PATHS — cannot reproduce 3 of 7 figures
- `load_cbd_experiment()` reads `results/simulation/cbd_experiment/` → **does not exist** (actual: `results/analysis/simulation/cbd_experiment/`)
- `load_capacity_comparison()` reads `results/capacity_comparison/` → **does not exist** (actual: `results/analysis/capacity_comparison/`)
- `FIG_DIR = results/figures/` → but figures were redistributed to `baseline/`, `analysis/`, `archive/`
- **Affected figures:** `fleet_sensitivity_dual.png` (Fig 3), `cbd_robustness_enhanced.png` (Fig 4), `capacity_sensitivity_heatmap.png` (Fig 6)

### ⚠️ MODERATE Issues

#### Issue 3: Technical report uses ARCHIVE figure when BASELINE equivalent exists
- **Figure 3** (`fleet_sensitivity_dual.png`): References `results/archive/figures/` but `results/baseline/figures/fleet_sensitivity_v2_dual.png` exists with updated content.
- **Rationale concern:** Archive tier is documented as "Legacy (superseded)" but Figure 3 is a core result.

#### Issue 4: `policy_comparison_panel_K20_cap2.png` has NO identified generating script
- **Referenced in:** `docs/core/technical_report.md:433` (Figure 1)
- No script in `scripts/` or notebook in `notebooks/` contains code that generates `policy_comparison_panel_K20_cap2.png`.
- `docs/core/figure_trace_guide.md` attributes it to "Production analysis pipeline" — this is vague and non-reproducible.
- The figure exists and is valid (642 KB), but provenance is untraceable.
