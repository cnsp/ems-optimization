# Processed Data

All files in this directory are **generated** by the data processing pipeline. They should **not** be committed to Git.

## Regenerating

```bash
# From project root:
make data              # Generate all processed data
make clean-data        # Remove all processed data
make verify-data       # Check if all files exist
python scripts/generate_all_data.py --force   # Force full regeneration
```

### Tier 2: Spatial Subsets

## Data Generation DAG

```
Raw GeoJSON boundaries
    -> Tier 1: Geometry pickles
        -> Tier 2: Spatial filtering (firehouses, precincts, crashes)
            -> Tier 3: Demand tables + Distance matrices
                -> Tier 4+: Optimization & Simulation (in results/)
```
